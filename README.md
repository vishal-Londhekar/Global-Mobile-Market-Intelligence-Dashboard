# Global Mobile Market Intelligence Dashboard

A Power BI portfolio project for exploring historical smartphone pricing, specifications, and brand positioning.

## Overview

This dashboard analyses 930 mobile models from 18 brands across the 2014–2025 period. It brings together regional price fields and product specifications such as RAM, cameras, processor, battery, screen size, and launch year.

The project is designed to demonstrate business intelligence workflows: data preparation, dimensional modelling, DAX measures, interactive filtering, and stakeholder-focused storytelling.

## Business questions

- How do brands compare across price tiers and markets?
- Which specifications are associated with higher prices?
- How have RAM, battery, camera, and screen trends changed over time?
- Where are potential positioning gaps or pricing outliers?

## Dashboard pages

- Overview: market and brand landscape
- Price Analysis: regional and brand-level price comparisons
- Features vs Price: specification and price relationships
- Matrix Visuals: comparative benchmarking by brand and model

## Files

- **Mobile Project.pbix** — Power BI workbook
- **Mobile Project.pdf** — exported dashboard preview
- **Mobiles+Dataset+(2025).xlsx** — source workbook

## Tools

Power BI Desktop, Power Query, DAX, Excel, star-schema modelling, slicers, and cross-filtering.

## How to view

1. Open **Mobile Project.pbix** in Power BI Desktop.
2. If Power BI asks for the source, reconnect it to **Mobiles+Dataset+(2025).xlsx**.
3. Use the page tabs and slicers to explore the analysis.
4. Open **Mobile Project.pdf** if you only need a static preview.

## Limitations

- The analysis uses a static dataset and is not connected to a live market feed.
- Currency fields should be interpreted using the source dataset's definitions; this project does not provide a live exchange-rate conversion layer.
- The dashboard is a portfolio demonstration, not a production reporting system.
